# Manual Cleanup: Removing the 'logs' folder via GitHub Web Interface

If you need to manually remove the `logs` folder from your repository to resolve conflicts or clean up history, follow these steps:

1.  **Open your Repository**: Go to your repository's main page on GitHub.com.
2.  **Navigate to Folder**: Click on the `logs` folder in the file list.
3.  **Delete a File**: GitHub doesn't allow deleting empty folders directly, but deleting the last file in a folder removes the folder.
    *   Click on a file inside the folder (e.g., `scraper.log` or `.keep`).
    *   Click the **Trash Can icon** (Delete this file) in the top right corner of the file view.
4.  **Commit Change**:
    *   In the "Commit changes" box, write a message like "Remove logs folder".
    *   Click the **Commit changes** button.
5.  **Repeat**: Repeat steps 3-4 for every file in the `logs` folder until the folder disappears from the repository view.

**Note**: Merging the Pull Request generated by this update will also automatically remove the `logs/` folder for you, so these manual steps are only necessary if you are fixing the main branch directly.
